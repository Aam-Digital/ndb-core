Edit Application Configuration Edit manually

Open the raw configuration in a JSON editor to make advanced technical adjustments. The previous configuration is kept as a backup and you can undo the change right after saving.

You can also download the configuration file, change it in an editor of your choice and upload it again. Uploading overwrites the current system configuration and accepts a single config object or an array of config documents.

Configure using AI Agents

Download a snapshot of all configuration documents from this system as a single JSON file. You can share this file with an AI assistant (e.g. ChatGPT, Claude) so it has the context needed to help you adjust configuration, reports, or forms. Apply the result with the upload above.

The download contains only structural configuration — no personal data or case records are included.

Included document types:

  • Application Configuration
  • Permissions
  • Configurable Enums
  • Site Settings
  • Report Configurations
  • Public Form Configurations
